# Projeto-Magr-o-Motos---Projeto-Extens-o-I
Magrão Motos

Sistema de gerenciamento financeiro para uma mecânica

O projeto será desenvolvido para facilitar o controle das entradas e saídas financeiras da oficina, o registro dos serviços realizados e a organização das informações sobre motos, clientes e peças utilizadas.
A aplicação será pensada principalmente para uso em celulares, com uma interface responsiva e possibilidade de instalação como PWA, oferecendo uma experiência semelhante à de um aplicativo.

Funcionalidades previstas

-Cadastro de clientes e motocicletas;
-Registro de serviços realizados;
-Cadastro e vínculo de peças aos serviços;
-Registro de movimentações financeiras de entrada e saída;
-Consulta do saldo e histórico financeiro;
-Relatórios simples sobre serviços, despesas e receitas.

Tecnologias

-HTML, CSS e JavaScript;
-Bootstrap;
-PHP;
-MySQL;
-PWA;
-Git e GitHub.

Objetivo

Desenvolver uma solução simples, acessível e de baixo custo para auxiliar a gestão financeira e operacional de uma mecânica de motos.
